# gis — Plateforme SIG open-source modulaire (alternative à ArcGIS Enterprise)

Études et conception d'une plateforme SIG open-source à **corps central + modules**, offrant la même
offre qu'ArcGIS Enterprise en plus performante, plus complète et sans lock-in.
