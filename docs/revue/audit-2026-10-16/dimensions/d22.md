# Audit d22 — API et standards (2026-10-16)

Lecture seule, aucune suite de tests exécutée. Le contrat `/v1` et le routage sont sains ; la surface « standards » revendique plus de conformité qu'elle n'en implémente. 11 constats : 8 Important vérifiés dans le code, 3 Minor non vérifiés. Non couverts faute de temps : `GetFeatureInfo` en détail, WMTS, `GET /v1/items`.

Re-vérification ponctuelle à la rédaction : `grep queryables|ogcapi-tiles` dans `core/app` = 0 résultat ; `ids` filtré en Python à `core/app/stac/routes.py:422` après `select_features` sans `ids`.

## Important

### 1. Conformance Features Part 3 revendiquée sans `/queryables` ni cql2-json [parite]
- Preuve : `core/app/features/routes.py:106-120` déclare `ogcapi-features-3/conf/filter`, `features-filter` et `cql2-text`. Aucune route `/queryables` (0 résultat). `filter-lang` n'accepte que cql2-text (`routes.py:~345`). La classe « filter » exige le document queryables ; cql2-json n'existe pas.
- Reproduction : `curl /v1/conformance` liste la classe filter ; `curl /v1/collections/{id}/queryables` renvoie 404.
- Correctif : `GET /collections/{id}/queryables` (JSON Schema dérivé de `info.columns`, champs masqués exclus via `hide_sensitive_columns`) + lien `rel=http://www.opengis.net/def/rel/ogc/1.0/queryables`. Implémenter cql2-json (parser vers l'AST de `cql2.py`) ou retirer les classes non tenues de `CONFORMANCE_CLASSES`.

### 2. OGC API Tiles servi mais jamais déclaré, ni TMS ni metadata [parite]
- Preuve : `core/app/ows/routes.py:263-336` sert `/collections/{id}/tiles` et `/tiles/{tms}/{z}/{x}/{y}`. Aucune classe `ogcapi-tiles` dans `CONFORMANCE_CLASSES` (`features/routes.py:106-120`). Pas de `/tileMatrixSets`, pas de metadata de tileset (`tilejson` = 0), pas de lien tiles sur la landing (`routes.py:124-146`). Seul WebMercatorQuad géré (`routes.py:~311`). Routes montées seulement si `CORE_OWS_ENABLED` (`main.py:464-466`), mais landing et conformance ne dépendent pas du flag.
- Reproduction : `GET /v1/conformance` sans classe tiles ; QGIS/MapLibre ne découvrent pas les tuiles depuis la landing.
- Correctif : classes `ogcapi-tiles-1/1.0/conf/core`, `mvt`, `tileset` conditionnées au flag ; `/tileMatrixSets/WebMercatorQuad`, metadata de tileset, liens `rel=.../tilesets-vector` sur landing/collection.

### 3. STAC item-search : paramètres ignorés en silence, `ids` appliqué après pagination [bug]
- Preuve : `core/app/stac/routes.py:302-308`, `SearchBody` sans `intersects`/`filter`/`sortby`/`fields` (pydantic ignore les champs inconnus), alors que `serializers.py:14` revendique `item-search`. Dans `_run_search` (`routes.py:417-422`), `select_features(..., limit=remaining, bbox=bbox, filters=None)` sans `ids`, puis filtre Python ligne 422 : un item au-delà des `limit` premières lignes n'est jamais retourné. `datetime` ne filtre que l'emprise de la collection.
- Reproduction : `POST /v1/stac/search {"ids":["<fid>"],"collections":["c"],"limit":10}` sur collection > 10 lignes, fid hors première page : `features=[]`. `{"intersects":{...}}` renvoie tout sans erreur.
- Correctif : pousser `ids` dans `select_features` (PK IN) ; ajouter `intersects` (`geom_intersects` existe) et `sortby` ; 400 sur paramètre non supporté ou retrait de la conformance ; `filter` via cql2.

### 4. `GET /v1/collections` hors profil OGC [parite]
- Preuve : `core/app/collections/routes.py:546-598` renvoie `{collections, numberMatched, numberReturned}` sans `links` racine. `_collection_json` (`routes.py:289-329`) sans `links`/`itemType`/`extent` ; seul `GET /collections/{id}` les ajoute (`~675-695`). `list_visible_collections` charge tout puis tranche en Python (`~575-578`). La landing (`features/routes.py:139`) pointe `rel=data` sur ce document.
- Reproduction : `GET /v1/collections` sans `links` ; QGIS ne trouve pas `rel=items` sans un GET par collection.
- Correctif : `links` (self/next) et par collection `links[items|self|queryables|tiles]` + `itemType` + `extent` ; limit/offset en SQL ; séparer profil standard et API produit.

### 5. WMS : version autre que 1.3.0 refusée, pas de GetLegendGraphic [parite]
- Preuve : `core/app/ows/wms_routes.py:250-251` (`only WMS 1.3.0 is supported`) pour GetMap et GetFeatureInfo ; 3 opérations servies (ligne 258). Clients anciens envoient 1.1.1 (axes lon/lat, `SRS`). Pas de GetLegendGraphic malgré styles déclaratifs et export SLD.
- Reproduction : `GET /v1/ows/wms?SERVICE=WMS&VERSION=1.1.1&REQUEST=GetMap&LAYERS=...` : ServiceException.
- Correctif : négociation à la baisse, support 1.1.1 (SRS, axes), GetLegendGraphic depuis les symbologies, annoncé dans GetCapabilities.

### 6. OpenAPI sans schéma de sécurité, peu de tags, version figée [differenciateur]
- Preuve : `core/openapi.json` : `components.securitySchemes` absent ; 23/199 opérations taguées ; 86 sans réponse 2xx typée. `core/app/main.py:184` : `version='0.1.0'` alors que v0.2.0 est livrée ; pas de `servers`. Auth par dépendances sans `HTTPBearer`/OAuth2 (`auth/dependency.py`, `apikeys/`) : pas de bouton Authorize, SDK générés sans flux d'auth.
- Reproduction : `python3 -c "import json;d=json.load(open('core/openapi.json'));print(d['components'].get('securitySchemes'))"` donne `None`.
- Correctif : `HTTPBearer` (JWT OIDC), `APIKeyHeader` (clés de service), schéma des liens de partage ; tags par routeur ; `response_model` manquants ; version dérivée de `pyproject`.

### 7. INSPIRE absent [differenciateur]
- Preuve : `grep -il inspire core/app` ne trouve que `ingestion/parsers.py` (import GML). Aucun export ISO 19139, aucune classe INSPIRE, WFS sans `ExtendedCapabilities` (`core/app/ows/wfs.py:61-140`), métadonnées de collection sans thème INSPIRE.
- Reproduction : aucune URL ne produit de métadonnées ISO 19139.
- Correctif : champs thème INSPIRE, mots-clés GEMET, conformité ; `/collections/{id}/metadata?f=iso19139` ; ExtendedCapabilities WFS (Download Service).

### 8. Pas d'OGC API Records ni de CSW serveur [differenciateur]
- Preuve : aucun `/records` ni `/csw` serveur (seule `core/app/harvest/routes.py:290`, interne). STAC (`stac/routes.py:128`) et DCAT (`dcat/routes.py:122`) ne listent que des collections de données. Cartes, apps, pipelines, rasters sans exposition standard.
- Reproduction : aucune route `/v1/records` ; un client CSW/Records ne peut pas moissonner GeoStudio, alors que GeoStudio moissonne CSW (SP-12).
- Correctif : OGC API Records (`/catalogues/main/items`, queryables, `f=json|html`) sur `items.search` (trigram+pgvector) et le moteur DCAT.

## Minor (non vérifiés)

### 9. STAC annonce `conf/oas30` alors que l'OpenAPI est 3.1.0 [bug] — non vérifié
- Preuve : `core/app/stac/serializers.py:17` ; REV-364 b appliqué seulement à `features/routes.py:108-109`. `core/openapi.json` : `"openapi": "3.1.0"`.
- Reproduction : `/v1/stac/conformance` contient oas30, `/v1/conformance` non.
- Correctif : retirer la ligne (jumelle oubliée, piège n°14) ; test comparant les deux listes.

### 10. WFS 2.0 minimal [parite] — non vérifié
- Preuve : `core/app/ows/routes.py:151-159` (3 opérations) ; GetFeature lit `bbox` et `cql_filter` (`~215-220`), ni `filter=` FES, ni `featureID`/`resourceId`, ni `typeNames` multiples ; pas de Transaction/GetPropertyValue.
- Reproduction : `...REQUEST=GetFeature&TYPENAMES=c&FEATUREID=1` : paramètre ignoré.
- Correctif : stored query `GetFeatureById`, traduction FES simple vers l'AST CQL2 ; WFS-T via la porte d'écriture Part 4.

### 11. DCAT-AP incomplet [parite] — non vérifié
- Preuve : `core/app/dcat/serializers.py:99-160` sans `dcat:keyword`/`dcat:theme`/`dct:conformsTo` ; distributions limitées à GeoJSON et STAC (~136-146) malgré exports CSV/GPKG/GeoParquet ; `dcat/routes.py:152` injecte `links` hors `@context`.
- Reproduction : `GET /v1/dcat/catalog` : pas de keyword/theme ; pagination inexploitable en RDF (pyshacl).
- Correctif : keywords/theme (vocabulaire EU MDR), distributions par format, `hydra:PagedCollection`, extension aux items publics.

Décompte : 8 Important vérifiés + 3 Minor non vérifiés = 11.

## Avantages et différenciateurs

- Contrat `/v1` et routage sains (33 routeurs sous `/v1`, health et `/mcp` exclus).
- OGC API Features Parts 1+4 avec écriture sous `can()`/RLS, CQL2-text, ETag/`If-Match`.
- STAC natif, DCAT-AP, moissonnage de 5 familles de connecteurs, WMS 1.3.0 / WFS 2.0 / tuiles MVT rendus par le cœur sous `can()`.
- Recherche sémantique (trigram + pgvector) réutilisable en standard via OGC API Records : différenciateur potentiel face à ArcGIS Hub.
- Différenciateurs manquants : INSPIRE, Records/CSW serveur, DCAT-AP enrichi.
