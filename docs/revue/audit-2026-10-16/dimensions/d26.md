# d26 — Accessibilité RGAA/WCAG

Audit en lecture seule. Aucune suite de tests ni rendu navigateur exécutés : les preuves sont des lectures de code.

## Socle solide (constaté)

- Focus visible par défaut ; `prefers-reduced-motion` global (`tokens.css:232`).
- Titre ARIA de la carte localisé (`MapView.tsx:323`).
- Popup avec focus initial et Échap ; mesure au clavier (Entrée au centre).

## Constats vérifiés

### 1. Important — Graphiques ECharts sans alternative accessible [différenciateur]
- Fichiers : `shell/src/builder/EChart.tsx`, `shell/src/builder/widgets/chart.tsx`, `shell/src/builder/widgets/indicator.tsx`.
- Preuve : `EChart.tsx:101` `echarts.init(el)` sans option `aria: {enabled:true}` ni `decal` ; conteneur `<div data-testid="echart">` sans `role="img"`, `aria-label` ni résumé ; aucun `aria:` dans `shell/src/builder` hors tests ; couleur seule voie de distinction entre séries ; clic sur un point (`chart.on("click")`, `EChart.tsx:103`) sans équivalent clavier.
- Reproduction : dashboard avec widget chart au lecteur d'écran (NVDA) : widget muet. Tab ne permet ni de lire une valeur ni de déclencher le cross-filter.
- Correctif : `aria.enabled` + `aria.decal.show` dans l'option ; `role="img"` + `aria-label` généré (titre, type, nombre de séries) ; bouton « Voir en tableau » rendant les mêmes données dans le `DataTable` du kit ; équivalent clavier au cross-filter (liste de catégories). Un graphique+tableau synchronisé serait un différenciateur RGAA face à ArcGIS Dashboards.

### 2. Important — Sélection d'entités de la carte impossible au clavier [parité]
- Fichiers : `shell/src/map/mapApplyLayers.ts`, `useMapPopup.ts`, `MapView.tsx`.
- Preuve : seuls déclencheurs du popup/cluster : `map.on("click", …)` (`mapApplyLayers.ts:218`, `:324`, `:342`). Aucun handler `keydown` ne parcourt les entités ; `MapMeasureSketchToolbar.tsx:360-366` n'écoute qu'Entrée pour ajouter un point d'outil. Pas de liste des entités visibles hors du widget table.
- Reproduction : focus sur le canvas, flèches puis Entrée : le popup ne s'ouvre jamais, ni le zoom sur cluster.
- Correctif : mode « parcourir les entités » (Tab/flèches sur `queryRenderedFeatures`, Entrée appelle le handler du clic), ou à défaut bouton « Liste des entités de la vue » ouvrant un panneau accessible (WCAG 2.1.1).

## Constats Minor NON VÉRIFIÉS en profondeur (lecture partielle, à confirmer)

La présence des attributs a été relue par grep ; l'effet sur les technologies d'assistance n'a pas été testé.

### 3. Minor — `aria-label` sur `<div>` sans rôle [bug] — non vérifié
- `MapTimePlayer.tsx:63` et `:103`, `MapSymbologyLegend.tsx:123` et `:155` : `aria-label` sur un `div` générique, nom non pris en charge (ARIA 1.2). Les `<ul>` (`:91`, `:110`, `:137`) ne sont pas concernés.
- Repro : lecteur d'écran sur le lecteur temps / la légende avancée : aucun nom lu.
- Correctif : `role="group"` (lecteur temps) ou `role="region"`/`group` (légendes) ; règle ESLint ou axe détectant `aria-label` sans rôle.

### 4. Minor — Lecteur temporel muet et bouton sans état [polish] — non vérifié
- `MapTimePlayer.tsx` : `setInterval` (~l.42) fait avancer la période sans `aria-live` ; bouton lecture/pause sans `aria-pressed`. La pause existe (WCAG 2.2.2 respecté).
- Correctif : `<span role="status" aria-live="polite">` à débit limité ; `aria-pressed={playing}`.

### 5. Minor — Légendes avancées : sens porté par la couleur seule [différenciateur] — non vérifié
- `MapSymbologyLegend.tsx` (~l.165-175) : bivarié = 9 `<span>` colorés sans texte ni `aria-hidden` ; comparer = dégradé CSS avec bornes ; densité/prédominant = pastilles. Seule la légende icône a `aria-hidden`. WCAG 1.4.1 partiellement non respecté.
- Correctif : description textuelle des classes en `sr-only`, pastilles `aria-hidden`, palettes validées daltonisme comme standard.

### 6. Minor — Résultats de recherche d'adresse non annoncés [polish] — non vérifié
- `AddressSearch.tsx:43` `role="alert"` (échec), `:48` `role="status"` (aucun résultat) ; la liste de résultats (~l.52-65) n'a ni région live ni compteur, ni rôle combobox/listbox.
- Correctif : `<p role="status" className="sr-only">{n} résultats</p>` ou migration vers le Combobox du kit.

## Avantages et différenciateurs

- Base a11y déjà acquise (focus, reduced-motion, popup, mesure clavier) : socle crédible pour une conformité RGAA revendiquée.
- Graphique + tableau synchronisé avec cross-filter clavier : différenciateur face à ArcGIS Dashboards (constat 1).
- Carte parcourable au clavier avec liste d'entités accessible : parité puis avantage sur les cartes web usuelles (constat 2).
- Palettes validées daltonisme + descriptions textuelles de légendes bivariées : standard produit rare (constat 5).
