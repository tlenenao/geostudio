# d01 — Cartes, symbologie, popups

Audit en lecture seule du code réel (2026-10-16). Aucun test exécuté. Les constats Important reposant sur un comportement MapLibre sont marqués « à confirmer en E2E ». Les constats Minor n'ont pas été vérifiés par lecture approfondie (marqués « non vérifié »).

Constats : 7 Important (vérifiés), 3 Minor (non vérifiés).

## Important

### I1 — Éditeur de carte : le changement de fond n'a aucun effet visible avant rechargement
- Tag : bug
- Preuve : `shell/src/map/MapView.tsx:321` passe `style: resolveBasemapStyle(config.basemap.style)` uniquement à la construction (effet à dépendances `[]`). Aucun `setStyle` dans `MapView.tsx` (grep vide). `MapEditorPage.tsx:151` met à jour `draft.basemap`, et le `<MapView>` de `MapEditorPage.tsx:256-258` n'a pas de `key` liée au fond. Seul le widget remonte la carte (`key={basemapOverride ?? "props"}`, `builder/widgets/mapWidget.tsx:372`).
- Reproduction : ouvrir `/maps/:id`, choisir un autre fond dans `BasemapSelect` : le canvas garde l'ancien fond ; après rechargement le nouveau apparaît.
- Correctif : effet sur `config.basemap.style` appelant `map.setStyle(...)` puis rejouant `applyLayers`/highlight/terrain/deck sur `style.load` (setStyle efface sources et couches). Minimal : `key={draft.basemap.style}` sur le `<MapView>` de l'éditeur, au prix d'un remontage.

### I2 — Fenêtre temporelle : effets, points de densité et étiquettes non filtrés
- Tag : bug
- Preuve : `applyTimeFilters` (`mapApplyLayers.ts:570`) ne filtre que `[r, r__icon, r__outline]`. `addEffectLayers` (`mapLayerBuild.ts:313-340`) crée `__fx_shadow/__fx_bloom/__fx_blend` avec le filtre de base de la couche, plus `__dots` et `__label`, tous dans `SUBLAYER_SUFFIXES` (`mapLayerBuild.ts:73-87`) : ils ne reçoivent jamais la clause temporelle. Seules les étiquettes sont documentées comme limite (commentaire l.543).
- Reproduction : couche avec `timeField` et `symbology.effects` (ombre/halo), lancer le lecteur temps : le point disparaît, son ombre/halo reste.
- Correctif : itérer sur toutes les sous-couches dérivées (`SUBLAYER_SUFFIXES` filtré par `map.getLayer`) ou une fonction unique `filterFor(layer)` partagée avec `applyLayers`. Pour `__dots`/`__label`, filtrer les entités avant `setData`.

### I3 — Fonds `xyz:` du tenant : pas de `glyphs`, étiquettes/clusters/mesures absents sans message
- Tag : bug
- Preuve : `resolveBasemapStyle` (`basemaps.ts`, branche `xyz:`) renvoie `{version:8, sources, layers}` sans `glyphs`. `addLabelLayer` (`mapLayerBuild.ts:271-274`) retourne false avec un `console.warn`. `addClusterLayers` (l.456) omet `__cluster_count`; `MapMeasureSketchToolbar.tsx:185` idem pour ses libellés. L'éditeur accepte `symbology.label` mais le rendu n'en montre aucune, sans message UI.
- Reproduction : fond de tenant `xyz:https://…/{z}/{x}/{y}.png` sur une carte à étiquettes ou clusters : aucun libellé ni compte.
- Correctif : ajouter `glyphs` au style minimal, servi par le cœur (`/v1/glyphs/{fontstack}/{range}.pbf`, auto-hébergé : offline et RGPD). À défaut, avertissement dans l'éditeur.

### I4 — Couches GeoJSON (`feature`) : le clic ignore `pkColumn`, pas de sélection/cross-filter sans id numérique
- Tag : bug (à confirmer en E2E sur PK texte)
- Preuve : `mapApplyLayers.ts:337-338` appelle `makeFeatureClickHandler(undefined, …)` pour la branche `feature` alors que le type porte `pkColumn`. Dans le handler (`mapLayerBuild.ts:384-390`), `id = f.id ?? fallback` avec `fallback = pkColumn ? properties[pkColumn] : undefined`, puis `if (id == null) return;` : `onFeatureClick` jamais appelé. MapLibre abandonne les `id` GeoJSON non numériques sans `promoteId`. Le popup, lui, ouvre bien (`onPopup` avant le return) : incohérence popup OK / sélection muette.
- Reproduction : couche `feature` sur collection à PK uuid, widget tableau lié : le clic ouvre le popup sans sélectionner la ligne.
- Correctif : passer `layer.pkColumn` à `makeFeatureClickHandler` ; ajouter `promoteId: layer.pkColumn` à la source geojson.

### I5 — Popup : valeurs de données injectées comme markdown (liens/images non fiables), liens sans rel/target
- Tag : securite
- Preuve : `interpolatePopupTemplate` (`popupTemplate.ts:79-98`) insère la valeur brute de `record.*` avant `marked.parse` (assumé dans l'en-tête du fichier). DOMPurify en config par défaut (`builder/widgets/sanitizeMarkdown.ts:11`) : `<img>` et `<a href>` http(s) passent, sans `rel=noopener noreferrer`/`target`. La CSP img-src est enforcing mais son allowlist est dynamique ; le lien de phishing reste cliquable.
- Reproduction : CSV dont une cellule vaut `[Réclamer](https://evil.example)`, popup à gabarit `**Nom** ${record.nom}` : lien actif dans un site public.
- Correctif : échapper le markdown des valeurs `record.*` (ou rendu en deux temps), hook DOMPurify `afterSanitizeAttributes` imposant `rel="noopener noreferrer" target="_blank"` et bloquant `img` hors origine hébergée.

### I6 — Parité ArcGIS : ni filtre par couche ni plage d'échelle
- Tag : parite
- Preuve : les variantes `vector`/`feature` de `MapLayer` (`api/types.ts` ~l.464-498) n'ont ni `filter`/`definitionQuery`, ni `minzoom`/`maxzoom`, ni groupes, ni blend mode. `applyLayers` (`mapApplyLayers.ts:79-345`) n'applique que `notAggregated()` et le filtre temporel. `LayersPanel` ne connaît que `cluster.maxZoom`.
- Reproduction : impossible d'afficher seulement `statut = 'actif'` ou de masquer une couche sous un zoom donné ; deux sous-ensembles stylés exigent de dupliquer la collection.
- Correctif : `filter?: { $expr: string }` (CEL compilé en expression MapLibre côté client et en `WHERE` pour ST_AsMVT sous rls_scope) et `minZoom/maxZoom` passés à `addLayer` ; éditeur dans `LayersPanel` avec l'assistant `generate_cel_expression` existant.

### I7 — Popup sans contexte CEL réel ni contenu riche
- Tag : differenciateur
- Preuve : `popupContent.ts` passe `{ vars: {}, user: { name: "" }, record: properties }` en dur (commentaire : contexte d'app non câblé, I4 SP-24). `PopupConfig` (`types.ts:454-459`) = `titleField/fields/template/attachmentField`. Relations (ARC-21) et métriques nommées non exposées au popup. Formatage fr-FR limité au mode `fields`, pas au gabarit.
- Reproduction : `${vars.commune}` ou `${user.name}` donne une chaîne vide ; pas de sparkline ni de lignes liées.
- Correctif : câbler `vars`/`user` via une prop `exprContext` de `MapView` ; étendre `PopupConfig` avec `blocks[]` déclaratifs (`chart` via /aggregate, `related` via relations ARC-21, `actions` via ActionBus) ; ajouter `fmt()` fr-FR au vocabulaire CEL.

## Minor (non vérifiés)

### M1 — Cellules agrégées `__agg` sans interaction
- Tag : parite
- Preuve : `mapApplyLayers.ts:207-208` pose `addAggregateLayer` sans handler, alors que la branche feature enregistre `makeClusterClickHandler` (l.321-328). `notAggregated` (`mapLayerBuild.ts:398-401`) masque aussi toute entité ayant une vraie colonne `point_count`.
- Reproduction : collection dense dézoomée, clic sur un cercle : rien.
- Correctif : handler `easeTo({center, zoom: zoom+2})` ; propriété réservée `__gs_count` côté ST_AsMVT.

### M2 — Export de style MapLibre lossy
- Tag : parite
- Preuve : `exportMapLibreStyle` (`mapLibreStyle.ts:44-107`) n'émet que la couche principale et `__outline` : ni `__label`, `__icon`, `__fx_*`, `__dots`, `__cluster*`, ni glyphs/sprite, fond, `timeField`. URL de tuiles reprises telles quelles (inutilisables hors GeoStudio sans jeton). L'import (l.115-190) ne recrée ni popup, cluster, étiquette et copie le `paint` étranger sans validation.
- Reproduction : export avec étiquettes ouvert dans Maputnik/QGIS : pas de libellés, tuiles en 401/404.
- Correctif : exporter les couches `symbol` avec glyphs/sprite du cœur, absolutiser via `getCoreUrl`, liste blanche `circle-*/line-*/fill-*` à l'import, documenter les pertes via `skipped`.

### M3 — Fonds par défaut : démo MapLibre et CDN Carto, aucun fond français
- Tag : differenciateur
- Preuve : `basemaps.ts:6-15` : `clair` = `demotiles.maplibre.org/style.json` (et `DEFAULT_BASEMAP`) ; `positron`/`voyager` sur `basemaps.cartocdn.com`. Les fonds de tenant (`/v1/basemaps`) ne sont pas proposés par `swipe.tsx`. Aucune couche Géoplateforme pré-câblée (grep `geopf` : seulement le géocodeur du cœur).
- Reproduction : nouvelle carte, fond mappemonde de démo ; zoom commune : aucune rue.
- Correctif : ajouter Plan IGN v2 / Ortho / Parcellaire Express, fond de repli de production, `useBasemaps` dans swipe/basemapGallery.

## Avantages et différenciateurs

- Moteur de symbologie déclaratif riche (catégoriel/continu/classé, effets, icônes, étiquettes CEL, clusters), partagé entre éditeur et widget.
- Tuiles vectorielles servies par le cœur sous `can()` + RLS, popups à gabarit CEL, pièces jointes, fonds de carte par tenant, export/import SLD et style MapLibre, lecteur temps.
- Base solide pour les correctifs proposés : CEL, `generate_cel_expression`, relations ARC-21, /aggregate DuckDB existent déjà.
